# Odoo Apps listing assets

The display title is **All-in-One Accounting Kit for Community**. The technical
module name stays `custom_accounting_kit`.

- Description: `static/description/index.html`
- Cover image: `static/description/banner.png` (also registered in the manifest)
- App icon: `static/description/icon.png`
- Search-oriented copy: manifest `name`, `summary` and `description`

The HTML uses Bootstrap 4 layout classes, inline styles, local PNG artwork and a
mailto support link. It contains no scripts, external fonts, embedded widgets,
fabricated screenshots, reviews or performance claims. Marketplace search ranking
is controlled by Odoo; this content makes the product's purpose and features explicit.

## Feature wording

- Aged Receivable and Aged Payable are selections in the Aged Partner Balance wizard.
- Accounting Dashboard refers to the standard Odoo Community journal dashboard.
- Recurring payments generate Odoo payment records; the listing does not promise
  automatic bank transfers or payment-gateway collection.
- The fiscal closing description refers to fiscal periods and the lock-date wizard.
- Existing installations of related standalone addons require a migration review.

Sources checked while preparing the content:
[Odoo Apps vendor guidelines](https://apps.odoo.com/apps/vendor-guidelines) and
[Odoo Apps submission information](https://apps.odoo.com/apps/upload).
The listing has not been submitted to the store.
